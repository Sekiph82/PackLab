# PackLab Studio Preview

This directory produces a disposable Windows preview from the canonical `main` branch.

It is intentionally separate from the production PackLab Studio implementation plan. It does not close or satisfy PL-0135, PL-0136, PL-0349, PL-0350, or any other production task.

Build output:
- PackLabStudioPreview.exe
- PackLabStudioPreviewSetup.exe

Run the Setup EXE to install the preview and create the desktop shortcut.
