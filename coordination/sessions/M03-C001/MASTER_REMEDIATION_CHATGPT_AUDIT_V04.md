## Remaining findings

Only the physical camera-control adapter evidence remains open.

### PL-0073
Production focus composition is wired, but the physical selected-device AVFoundation adapter is not behavior-tested for wrong-device rejection, adjusting→stable observation, lock-before-stable failure and lock-after-stable success.

### PL-0074
Production exposure composition and accepted-photo metadata wiring exist, but the physical selected-device adapter is not behavior-tested for wrong-device rejection, serialized configuration, clamp/lock behavior and persisted exposure/ISO evidence.

### PL-0075
Production white-balance composition and accepted-photo metadata wiring exist, but the physical selected-device adapter is not behavior-tested for wrong-device rejection, real stabilization gating, lock timing and persisted WB evidence.

## Disposition

Next work is a very narrow **M03-BATCH-006** containing only PL-0073, PL-0074 and PL-0075.

The remediation must preserve the existing camera architecture and add a production-used injectable camera-device-control driver/seam so these AVFoundation behaviors can be proven deterministically without requiring the Windows builder to execute native iPhone/Xcode tests.

Decision: **CHANGES_REQUIRED**
