## M12 authority model

M12 extends the accepted M11 parametric DESIGN_MODEL system into more complex packaging families.

The authority stack remains:

```text
SCAN_MASTER (captured reference, when available)
  -> exact pinned parent binding
  -> DESIGN_MODEL parametric graph
  -> M12 family/component/freeform/assembly revisions
  -> PREVIEW_PROXY / diagnostic / export-handoff metadata
```

Hard rules:

- Scan Master is never rewritten.
- Design Model truth remains versioned parameters/features/operations, not scan triangles or preview triangles.
- Freeform/cage deformation is an editable Design Model operation, not captured truth.
- Reusable trigger/pump library components are design/reference assets and require explicit provenance/license/integrity metadata.
- No network auto-download or silent acceptance of unknown/unlicensed component files.
- Component swaps create new assembly revisions and never silently deform bottle geometry.
- Flexible-pack models are explicitly **visualization/design geometry**, not mold-grade captured/manufacturing geometry.
- PL-0220 through PL-0224 remain `DEFERRED_OWNER_VALIDATION`.
- `METRIC_UNVERIFIED` / `mm_unverified` remains unverified.
- No M13 CAD/BREP/OpenCascade/STEP implementation is authorized.

## Family-specific guardrails

### Jerrycan / handles

- Body fitting may use symmetric or asymmetric stacked sections.
- Handle opening and grip/indent are explicit editable features.
- Missing scan evidence must remain missing.
- Cage/freeform edits must preserve configured key dimensions/symmetry or fail.
- PL-0275 is a software/geometry benchmark only, never a physical accuracy substitute.

### Trigger / pump assemblies

- Assembly graph components retain immutable revision identities.
- Library imports require explicit digest, version, source and license/provenance.
- Neck alignment uses accepted mating references only.
- Dip tube geometry is parameterized and does not infer unseen real-world dimensions.
- Collision/interference is diagnostic, not certified fit.
- Variant swaps never mutate body geometry.
- PL-0282 produces export-handoff/component hierarchy metadata only; M13 owns CAD/STEP realization.

### Tube / sachet / flexible packs

- Tube dimensions preserve source provenance: captured, explicit reference or modeled.
- Wall thickness/material deformation is not inferred unless explicitly provided later.
- Sachet/pouch geometry prioritizes artwork/layout/overall dimensions and seal zones.
- Flexible-pack surfaces may use simplified design bulges but must not claim measured film deformation.
- Flexible-pack outputs must remain clearly visualization/design authority and cannot become Scan Master or mold/manufacturing truth.
- Package-family conversion must be intentional, versioned and explicit about unmapped features.

## Stop conditions

- validation failure that cannot be corrected within frozen child scope;
- synchronization/tracker mismatch;
- architecture/provenance/authority conflict;
- missing mandatory capability/evidence;
- unreviewed dependency/library/license issue;
- privacy/security issue;
- owner decision requirement;
- need to start M13 or later work.

On stop:
1. publish the current child blocker/evidence log;
2. update master log as `BATCH_STOPPED`;
3. record exact child/reason;
4. preserve previous green evidence;
5. end exactly `AWAITING_MILESTONE_AUDIT`;
6. stop.
