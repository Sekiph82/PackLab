# PL-0420 Validation Criteria V01 — Learned Packaging Feature Recognition Research

1. Research report distinguishes 2D image segmentation from semantic 3D part recognition and geometry-based feature detection.
2. It compares at least two implementation paths, identifies data/label and evaluation needs, and recommends a bounded first implementation.
3. Every external technical/license claim cites an official repository, model card/license, or primary paper; code and checkpoint licensing are considered separately.
4. It records privacy, deployment/source-visibility, human-confirmation, and Scan Master/measurement authority boundaries.
5. It selects no runtime model and performs no package/checkpoint download, installation, inference or training.
6. No private owner imagery or data is accessed or uploaded.
7. `git diff --check` passes.
8. No GitHub Actions/paid CI, PR, main source push, native OCCT/OCP/Installer build, or hosted/device/release claim occurs.
