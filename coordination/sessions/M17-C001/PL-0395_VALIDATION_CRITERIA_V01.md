# PL-0395 — Validation Criteria V01

1. V1 software capabilities and verified/nonverified conditions are stated with evidence boundaries.
2. Scale, optical/material, reconstruction, editable-fit, STEP/export, device, hosting and Kenya-production gaps are explicit.
3. Documentation states clearly that outputs must not be used directly to manufacture a mold or authorize production.
4. Physical measurement, print fit, supplier/material facts, certification, regulatory review and owner decisions remain distinct gates.
5. No generated data or local software result is represented as physical or hosted evidence.
