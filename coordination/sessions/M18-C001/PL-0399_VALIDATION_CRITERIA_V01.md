# PL-0399 — Validation Criteria V01

1. Establish a default no-treatment decision and try non-contact capture changes (diffuse lighting, background, viewpoint, exposure, optional PL-0398 polarization) first.
2. Any treatment path requires the exact product's current technical data sheet and SDS, applicability to the intended object/use confirmed by product owner/manufacturer, local site EHS approval, material/finish/ink/adhesive compatibility evidence from sacrificial equivalent material, and a preapproved, product/site-specific stop, incident-response, cleanup-or-no-cleanup, containment and final-disposition plan. Missing any gate means no application.
3. Explicitly prohibit treatment on items intended for food contact or with unknown use/contents; cite manufacturer limits. For AESUB Blue specifically, record the current SDS restriction against private/household use as well as food-contact use. Do not equate the project's noncommercial purpose with a household work setting; applicability requires review of the exact intended site/use and current regional SDS.
4. Address aerosol/solvent hazards, ventilation, ignition control, PPE, containment/equipment protection and waste per the exact current SDS and local EHS. Do not improvise a substitute cleaning solvent.
5. Explain coating thickness can bias geometry/dimensions; do not accept treated dimensions as uncoated production reference unless the layer and metrology correction are independently quantified/validated. Preserve pre-treatment images/measurements and treatment provenance.
6. If tested later, start with a sacrificial coupon of matching resin, colorant, coating, print/ink and adhesive, inspect for swelling, crazing, gloss/color change, tack, ink transfer, residue, and removal response; never proceed from a generic resin name alone.
7. Cite primary manufacturer documentation and qualify every product claim; no product is chosen or used and no physical, safety, Kenya, software or production trial is claimed in this task.
8. No software tests are applicable; record milestone suite deferral and both independent advisory review outcomes, limitations, publication status, and `LOCAL_COMPLETE_AUTONOMOUS_QUEUE_ARMED` only if criteria are met.
