# PL-0396 — Validation Criteria V01

1. BOM lists quantities, minimum function/specification, and explicit maximum footprint, height and gross load; 5 L packaging is only in scope if it fits.
2. Low-cost baseline uses manual, non-motorized components; optional upgrades are separate and not required for capture.
3. Camera support, diffuse high-CRI/flicker-free lighting, matte background, turntable, and calibration/reference targets are addressed.
4. COLMAP camera/object motion constraints are called out with an authoritative software source; the document prohibits merging changed object orientations into a standard image set unless that motion workflow is specifically validated.
5. External references are current and direct; Kenya procurement/prices remain explicitly unverified.
6. No purchase, hardware test, Kenya scan, or physical repeatability pass is claimed.
