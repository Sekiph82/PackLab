# PL-0413 — Validation Criteria V01

1. SOP covers receive/authorize, safety and condition, cleaning decision, station readiness/calibration, capture, source preservation, reconstruction QA, dimension/fit review, independent audit, library disposition and backup/handoff.
2. Every phase states entry prerequisites, record/evidence, exit criteria, stop/quarantine/escalation route and accountable role.
3. Cleaning/treatment follows PL-0399; capture follows PL-0400/PL-0397 and keeps calibration/object/polarization/treatment sets properly separated.
4. Preserve stable asset identity, immutable revision/source lineage, field provenance, unknowns, licensing/permission and status semantics consistent with PackLab schemas; no fake acceptance status, authoritative scale, or production approval.
5. Explicitly gate physical use on PL-0401 station repeatability, suitable independent measurement/calibration, and owner/site safety approval. State that threshold values and site roles need future local validation.
6. Include fail/retry and no-go cases for unsafe/unknown sample, label/material change, missing coverage, poor reconstruction, scale gaps, dimensional mismatch, unlicensed source, treatment residue and storage/restore failure.
7. No actual Kenya site, sample, capture, repeatability, calibration or production run is claimed. Documentation-only; no tests/physical testing. Advisory source/security reviews inspect actual doc.
