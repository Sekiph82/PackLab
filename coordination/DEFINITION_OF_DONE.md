# PackLab Definition of Done (Claude handoff 2026-11-10)

**IMPLEMENTED_NOT_ACCEPTED:** real code/document/fixture exists, but mandatory tests or separate review not satisfied. Checkbox stays unchecked.

**CLAUDE_PEER_AUDITED_PASS:** actual task requirements, focused/negative/regression tests, mandatory hosted/system checks where applicable, independent non-implementing Claude source/security review, privacy/license data provenance and versioned evidence are verified. Claude coordinator may then update sole root `TASKS.md` checkbox and publish/sync it. This is a distinct owner-authorized peer-reviewed acceptance, never disguised as historical ChatGPT `AUDITED_PASS`.

**CHANGES_REQUIRED:** material defect/test failure; keep same ID open, remediate, retest, re-review and append evidence.

**IMPLEMENTED_REVIEW_PENDING:** peer review unavailable or not independently run; keep unchecked and do other ready work.

**EXTERNAL_PENDING:** actual real-world printer/physical sample, iPhone validation, nonexistent factory data, owner Apple credentials, legal compliance or external CI capability missing; keep affected criterion and any dependent task unchecked while independent software tasks proceed.

**MILESTONE_COMPLETE:** only after all mandatory tasks and their actual physical/CI/license/owner acceptance requirements pass. Synthetic CAD/photo calibration checks can validate simulated pipelines but not physical accuracy. Unsigned iOS artifacts are not signed IPAs. Nonproduction preparation is not factory rollout.

**Non-negotiable:** preserve genuine PackScan evidence, design/scan separation, metric units, public-repo secrets safety, immutable historical audits and safe owner Desktop data. GitHub `main` remote and local parity must be actually checked or marked `LOCAL_SYNC_PENDING`. No fabricated PASS or hidden substitute for E4 truth.
