Claude Code is sole project orchestration and implementation authority. Its `packlab-builder` and `packlab-dataset-curator` subagents implement **assigned permanent PL tasks only**, using current `TASKS.md`, mandatory technical pre-reads and existing accepted source/contracts; the coordinator may schedule new tasks continuously without a separate Codex/ChatGPT prompt.

Before editing: inspect repository/branch/dirty owner state, affected code and tests, preserved historical findings and data/security boundaries. During development: record actual source/base SHA, changed files, focused and negative/regression results, failures, fixes, limitations and relevant GitHub Actions run IDs. Do not invent test output or real camera/factory/physical evidence. Builder does NOT certify its own independent audit or mark tasks complete; non-implementing reviewer and security specialists must inspect actual evidence.

Claude coordinator alone updates root `TASKS.md` after real verification; `[x] CLAUDE_PEER_AUDITED_PASS` requires all required gates. On `CHANGES_REQUIRED` remediate same PL ID. On missing external signing/legal/physical evidence, preserve `[ ] EXTERNAL_PENDING` with re-entry condition and continue dependency-independent tasks. Keep review and implementation file ownership distinct.

After each genuine acceptance, publish tracked scope and verify GitHub/owner Desktop SHA via non-destructive synchronization. Never force Git, delete owner work/private evidence, leak secrets/private Kenya data, or invent public/factory release authority.
