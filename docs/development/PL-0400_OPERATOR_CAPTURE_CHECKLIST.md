## B. Stop before touching or cleaning

- [ ] Package is dry, stable, and safe for non-contact exterior imaging; no leak, unknown residue/liquid, pressure, odor or contamination concern. If any concern exists: **STOP all capture and handling.**
- [ ] Intended use and contents-contact status are known. If unknown or the object is filled: **STOP; do not open, clean or apply treatment.** Non-contact exterior capture may proceed only if the sample owner and site policy explicitly confirm it is safe and permitted; otherwise stop.
- [ ] Material is known or explicitly marked unknown. If unknown, do not clean or treat; obtain owner/site safety authorization before handling or imaging. Proceed only with safe, authorized non-contact exterior imaging if that review permits; otherwise stop.
- [ ] For a package intended for food, medicine, cosmetics or other regulated contents: do not clean, open, or apply any treatment. Non-contact imaging of a confirmed empty, safe-to-handle exterior requires owner/site authorization; do not imply this checklist approves regulatory-contact or production use.
- [ ] Photograph exterior condition and every label/artwork panel before setup. Record existing scuffs, dents, seams, closures, loose edges, tears and prior damage.
- [ ] If damage could affect safe handling or label integrity, stop and obtain owner disposition. For loose labels, tears or uncertain adhesion, do not touch or manipulate; continue only with explicitly authorized non-contact exterior imaging, otherwise stop.
- [ ] Leave labels, seals, caps, triggers, pumps, tamper evidence and print in place. Do not peel, flatten, re-stick or cover labels/artwork with targets.
- [ ] Cleaning is needed: ☐ No ☐ Yes. If yes, do not clean until the package owner has approved a method for this exact material/label/finish/use and its safety is confirmed. Record approved method and authorization: ______________________________
- [ ] If any cleaning or other owner-approved alteration is authorized, record before-image ID(s), after-image ID(s), method, material/use review and approval reference: ______________________________
- [ ] Do not apply solvent, detergent, alcohol, water, tape, powder, paint or scanning spray by default. Any proposed removable treatment must pass every PL-0399 gate and be separately authorized. If unclear: **STOP untreated.**

## D. Capture sequence — standard fixed-object set

COLMAP's image-based reconstruction guidance calls for overlapping views, similar illumination within a set, avoidance of strong specular highlights, and camera viewpoints that actually change. For this PackLab baseline, keep the package stationary in one orientation and move the camera. Do not rotate the object between subsets and merge them into a standard set without validating that alternate workflow.

- [ ] Place package and any fixture without covering package features, labels, openings, handle voids, seams or closure details. Keep non-object background stationary.
- [ ] Take calibration-board photos as a separate calibration-only set with the object area empty, then remove the board before package capture. Do not import calibration-only photos into the ordinary package reconstruction image set.
- [ ] Include a known-length scale reference in package images only when the selected capture protocol calls for it and it does not obscure package features. Record its identity/units; do not claim traceability unless its calibration evidence establishes it.
- [ ] Capture a complete image all around at the documented lower/body/upper viewpoints, plus top/base/opening details where safely visible. Move the camera between stations; aim for each important surface region in at least three overlapping views.
- [ ] Keep camera intrinsics and exposure/focus/white-balance stable within the set. Avoid clipping, motion blur, abrupt light changes, strong shadows and highlight positions that hide surface features.
- [ ] Before considering treatment, try/record non-contact options: ☐ diffuse/soften light ☐ reposition lights ☐ matte contrasting background ☐ adjust camera viewpoint/azimuth ☐ set stable exposure. Result / remaining glare zones: ______________________________
- [ ] Image names and set ID are unique and in sequence. Record camera path/viewpoint count: ______________________________
- [ ] Cross-polarized option used? ☐ No ☐ Yes. If yes, this is a separate paired set; record filter angle, lighting/exposure and identify baseline counterpart: ______________________________. PL-0398 trial remains unvalidated.
- [ ] Any treatment used? ☐ No ☐ Yes. If yes, stop and complete every PL-0399 gate before application. If any evidence/approval is missing, do not apply or continue with a treated set.

## E. Immediate image and sample QA

- [ ] Images open and are sharp; no missing viewpoints, severe reflections, clipped areas, moving background, focus/exposure jumps or corrupted files.
- [ ] Labels/artwork remain legible and unobstructed. Package remains unchanged; record any new mark, tack, color/gloss change, residue or handling damage and quarantine/notify owner if present.
- [ ] Required scale/calibration evidence and actual camera/light settings are recorded. Unmeasured/unverified fields are explicitly marked unknown.
- [ ] Capture outcome: ☐ Ready for software processing ☐ Recapture needed ☐ Stop/owner review. Reason / affected regions: ______________________________

## Evidence and validation boundary

This checklist is a proposed operator aid. The camera, light and turntable coordinates remain unvalidated starting points from PL-0397; PL-0401 remains responsible for physical repeatability. A completed paper form does not establish dimensional accuracy, calibration traceability, safe handling, material compatibility, successful reconstruction, Kenya-site acceptance or production readiness. No physical sample or Kenya site was available or tested for PL-0400.
